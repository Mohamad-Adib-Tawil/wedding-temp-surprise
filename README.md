# Wedding Temp Surprise

Static Arabic wedding invitation with the reference story sequence, video, audio, RSVP, and calendar links. It is deployed as a GitHub Pages site.

Edit `config.js` to change names, event details, contact/order links, copy, and asset paths. Replace files in `assets/` to change the visual media.

The RSVP form opens a prefilled WhatsApp message to the configured contact. Guests complete sending from WhatsApp; GitHub Pages does not provide a server to collect responses.
